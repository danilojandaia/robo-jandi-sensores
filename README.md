# Teste dos sensores do tablet do robô Jandi

Página estática para medir acelerômetro, giroscópio e bússola do tablet que será a cabeça do robô de recepção da Prefeitura de Jandaia/GO.

Abra em: https://danilojandaia.github.io/robo-jandi-sensores/

Nada é enviado para servidor: os resultados ficam na tela e são copiados manualmente.
