# Teste dos sensores do tablet do robô Jandi

Página estática para medir acelerômetro, giroscópio e bússola do tablet que será a cabeça do robô de recepção da Prefeitura de Jandaia/GO.

Abra em: https://danilojandaia.github.io/robo-jandi-sensores/

Nada é enviado para servidor: os resultados ficam na tela e são copiados manualmente.

## Teste real do robô no iPhone

Abra em: https://danilojandaia.github.io/robo-jandi-sensores/teste/

Câmera frontal com detecção de rosto (MediaPipe, roda no aparelho), olhos e pescoço simulado seguindo o rosto, fala por reconhecimento de voz do Safari, resposta do Claude com voz pt-BR e a ferramenta `ver_camera`. A chave da Anthropic é digitada pelo próprio usuário e fica só no aparelho: use uma chave de teste com limite de gasto. No robô de verdade a chave fica no servidor, nunca no tablet.
